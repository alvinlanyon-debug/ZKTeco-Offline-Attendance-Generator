Download from GitHub

Get the app in four steps.

GitHub downloads the whole project as a ZIP. The app you want is already included—there’s no installer or build step.

  1. 01

    Open the project

    Go to the Zen AtGen GitHub repository.

  2. 02

    Choose “Download ZIP”

    On the repository page, select the green Code button, then choose Download ZIP. Save and extract the ZIP on your computer.

  3. 03

    Open the included app

    In the extracted folder, open docs, then open index.html in a modern browser. That is the ready-to-use local app.

  4. 04

    Load your device exports

    Select attlog.dat and, if you have it, user.dat. Keep the original files in a safe place; the app does not upload them.
