1 Load Device Files

Transferring attendance data from your hardware

Note: Menu terms vary by ZKTeco hardware model and firmware version.

1. Download Attendance Logs

  1. Insert a USB drive into the ZKTeco device.
  2. Press M/OK to open the main menu.
  3. Select the USB / PenDrive icon.
  4. Choose Download.
  5. Select Attendance Data (or Att Data).
  6. Select the date period (e.g., Daily/Weekly/Monthly).
  7. Save attlog.dat to the USB.

2. Download Staff Names (Optional)

  1. Return to the main device menu.
  2. Open the User / Personnel / User Mgt section.
  3. Select Download User Data to save user.dat.
  4. Carefully remove the USB drive.
  5. Connect the USB drive to your computer.
  6. Upload the files below.

2 Staff Roster & Classification

Names from user.dat are auto-filled. Select a group for each employee: Security Guard (for hourly mandate compliance), General Worker, or Unclassified. Settings are saved locally.
